## Recommendation

**What the evidence shows.** The frozen JP1.1 mechanism is **supported in this bounded validation**:
- on four new families it changed two calls, and both moved closer to the truth over the coupled interval (5 → 3 and
  14 → 0 bp) and reduced locus excess (−6 and −13);
- it changed nothing in the other two families or in either correct control;
- it cost little.

**Limits:**
- four families, one locus, one coverage, one eligible block;
- families, not blocks, are the units, so this is small-sample evidence;
- block-label exactness does not register the improvement because of the sv:5..ctx:6 degeneracy.

**No default promotion.** It stays `experimental_v1`, default off.

**A reasonable next step, if wanted, is a separate predeclared batch that tests what this one did not:**
- loci other than ACOT with marker-uninformative blocks;
- a second coverage;
- a larger family count, using the remaining 18 ACOT families.
